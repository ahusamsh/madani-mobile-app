# المعمارية وقاموس البيانات — القاعدة المدنية التفاعلية

## 1. هدف المنتج وسلوك القراءة

الكتاب التعليمي يُعرض عبر PWA. عند تصوير أي جزء معروف من صفحة الكتاب والإشارة إلى كلمة بإصبع السبابة أو القلم، يُشغّل التسجيل الصوتي الأصلي الصحيح عند توفره. اللمس داخل كلمة متعددة الحروف يختار الكلمة كلها؛ الحروف والمقاطع التعليمية المنفصلة تُنطق وفق نوعها. يُرفض القرار غير المؤكد ويُمنع النطق عند غياب المؤشر.

## 2. مسار التنفيذ الحي

```text
Camera getUserMedia
  -> vision/v2/frame-source.mjs (التقاط الإطارات ودقة تكيفية)
  -> vision/v2/vision-worker.mjs (Web Worker مستقل)
  -> vision/v2/engine-v2.mjs أو vision/v3/engine-v3.mjs
  -> فهرس الصفحة + المطابقة الهندسية + تحقق الصورة
  -> اكتشاف الإصبع أو القلم وطرف الإشارة وتثبيته زمنيًا
  -> تحديد منطقة الحرف/المقطع/الكلمة وعتبة الثقة
  -> data/audio-library.json -> segment.clip
  -> vision/v2/audio-controller.mjs -> ملف MP3 أصلي
```

التطبيق لا يرسل إطارات الكاميرا إلى خادم AI. عند تعذر الصفحة أو طرف المؤشر أو تضارب الجيران لا يشغّل صوتًا. الواجهة في `vision/camera-v2.html` و`vision/camera-v2.mjs`، ويمكن اختيار المحرك بـ `?engine=v3` **فقط في فرع V3 أو معاينته**؛ V2 افتراضي.

## 3. الشيفرة حسب المسؤولية

| المسار | الوظيفة |
|---|---|
| `index.html`, `app.js`, `style.css` | عارض الكتاب الرئيسي والتنقل |
| `vision/recognition-core.mjs` | أدوات مطابقة الصورة والمصفوفات |
| `vision/engine/` | التعرف الأساسي V1: سمات الصفحة والتسجيل الهندسي والمؤشر واختيار الهدف |
| `vision/v2/` | تتبع واستقرار أفضل، Web Worker، فصل الصوت، إدارة حزم Offline |
| `vision/v3/` | في فرع V3 فقط: مطابقة الحبر الفعلي واختيار الحرف وتمييز الصفحات المتشابهة |
| `vision/bench/` | مولد الفهرس واختبارات محاكاة الإشارة وتقارير المقارنة |
| `vision/data/ref-index.bin` | فهرس مسبق الحساب لـ104 صفحات لتوفير تكلفة الاستخراج على الجوال |
| `vision/reference-pages/` | صور مرجعية محلية تكمل الصفحات الناقصة |
| `sw.js`, `manifest.webmanifest` | تشغيل PWA والتخزين المحلي والتحديث |

## 4. مصادر البيانات

- `books/<lang>.pdf`: الكتب المترجمة؛ العربية `books/ar.pdf` هي المرجع الأساسي للرؤية الحالية.
- `data/editions.json`, `data/edition-maps/<lang>.json`: الطبعات ومواءمة صفحات الترجمات. لا تفترض أن جميع اللغات لها الصوت العربي مطابقًا.
- `data/audio-library.json`: `pages[pageNumber]` يحوي الصورة ومناطق `zones`، وقد يتضمن التسجيل الكامل؛ `segments[zoneId]` يحوي `clip` و`page` وحالة المراجعة والمصدر.
- `data/audio-coverage.json`: تقرير تغطية مشتق، لا يُحرّر يدويًا.
- `data/offline-packs.json`: Manifest ملف لكل حزمة (مسار، حجم بايت، SHA-256). مشتق من الملفات الفعلية.
- `pilot-media/`: ملفات مقاطع الدروس الأولى.
- `library-audio/`: تسجيلات الصفحات الكاملة الأصلية (مقاطع كبيرة).
- `library-clips/`: مقاطع مفصولة أو معاد استعمالها من التسجيل الأصلي، وقد تشير مناطق متعددة للملف نفسه.
- `vision/alignment/`: ملفات أدلة ومحاذاة ASR/OCR وتقارير تربط مصدر النص بالمقطع؛ ليست دليل تحقق بشري.

## 5. مخطط ربط صوت نموذجي

```json
{
  "pages": {
    "17": { "image": "...", "zones": [{ "id": "p17-w5", "text": "ج", "kind": "letter", "box": [0.1, 0.2, 0.03, 0.04] }] }
  },
  "segments": {
    "p17-w5": { "page": 17, "clip": "./pilot-media/p015-word-005.mp3" }
  }
}
```

المثال توضيحي للبنية؛ القيم الفعلية للمستطيلات موجودة في الملف ولا ينبغي نسخ الأبعاد من المثال. `reviewed:false` أو أي `status` يحتوي `pending` يعني أن المطابقة الآلية لم تعتمد بالاستماع. لا تصنّف الرابط على أنه منجز بشريًا دون عملية مراجعة فعلية.

## 6. الفرق بين V2 وV3

V2 يطابق الصفحة بصريًا ثم يعتمد بدرجة كبيرة على مستطيلات المناطق المستخرجة آليًا. V3 يضيف `ink-layout.mjs` لالتقاط كتلة الحبر المطبوع داخل الصفحة المرجعية و`target-v3.mjs` لاختيار الحرف وفق الموضع والاتجاه، و`page-discriminate.mjs` لتمييز تخطيطات متشابهة كصفحتي 47 و49. هذه **ليست OCR عربية مستقلة**: لا يزال V3 يستخدم الصورة المرجعية والبيانات الحالية.

## 7. التخزين دون إنترنت

الـService Worker يحمل ملفات shell للمحرك، ويستخدم حزم تنزيل يختارها المستخدم. `camera-ar` لازمة للرؤية والنطق العربي، و`book-ar` للكتاب، وحزمة التسجيلات الكاملة اختيارية. التنزيلات الأولى تحتاج إنترنت، أما التشغيل اللاحق فيجري على الجهاز. لا تُعلن الجاهزية قبل اكتمال الملفات والتحقق من SHA-256، وتوقّع اختلاف سعة التخزين بين الأجهزة.

## 8. الحدود التقنية الحالية

- فهرسة الصورة لا تضمن قدرة فعلية على التعرف على كل صفحة عند ظهور جزء صغير أو إضاءة سيئة.
- صفحات ضعيفة المعالم أو تشترك في حروف متشابهة تحتاج تحققًا إضافيًا؛ V3 يحسن ذلك لكنه غير معتمد ميدانيًا.
- خرائط نصية لبعض الصفحات، خصوصًا 60 و80 و100، تحتوي أخطاء وتحتاج تدقيقًا قبل اعتبار الكلمة/الصوت صحيحين.
- لا تصح إعادة استخدام تسجيل كلمة أخرى إلا مع تطابق النص والتشكيل والمقصود التعليمي والتحقق من المصدر.
- التحليل على هاتف متواضع قد يختلف كثيرًا عن أرقام الاختبارات على Node/Chrome المكتبي.
