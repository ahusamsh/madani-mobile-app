# مكتبة الصوتيات — بناء الرابط والتحقق والمراجعة

## 1. المبدأ

الصوت الذي يُسمع عند الإشارة إلى الحرف أو الكلمة يجب أن يكون من تسجيلات القاعدة المدنية الأصلية، وأن يطابق المادة التعليمية والتشكيل. **ممنوع ملء الفراغات بـTTS أو بمقطع قريب تخمينًا**. عدم النطق عند انعدام الرابط أدق تربويًا من تشغيل تسجيل خاطئ.

## 3. شرح الملفات

- `data/audio-library.json`: المصدر المعتمد لـ`pages[pageNo].zones[]` و`segments[zoneId]`.
- `library-audio/`: التسجيل الكامل للصفحة الأصلي؛ في بعض الصفحات تشتق أسماء الملفات من رقم الصفحة ناقص 2.
- `pilot-media/`: تسجيلات مقسّمة قديمة تربط مواضع أوائل الكتاب.
- `library-clips/`: MP3 قصيرة مستخرجة من التسجيلات، وأحيانًا نسخ معاد استعمالها لحرف مطابق.
- `vision/alignment/transcripts/`: تفريغ ASR مع توقيت الكلمات؛ دليل آلي غير معتمد بالاستماع.
- `vision/alignment/ocr/`: نتائج OCR من الصور المرجعية؛ قد تشوه الكلمات والحركات.
- `vision/alignment/*audit*.json`: مسارات أدلة إعادة الاستعمال والمحاذاة.
- `data/audio-coverage.json`: تقرير مشتق للتغطية وعدد المواضع بلا ربط.
- `vision/alignment/unmatched-words.json`: مناطق تحتاج عملًا إضافيًا.

## 4. مسار إنتاج مقطع جديد

```text
original page MP3 + source page PDF
  -> تفريغ وتوقيت عربي محلي (ASR)
  -> كشف النص وموقعه بصريًا (OCR / PDF)
  -> مطابقة مقيّدة بالصفحة والكلمة والحركات
  -> قصّ MP3 الأصلي مع وقت البداية/النهاية
  -> segment entry + source provenance + reviewed:false
  -> فحص الارتباط، الملف، الحدود، واختبارات التراجع
  -> مراجعة استماعية بشرية قبل وصفه بأنه معتمد
  -> تحديث تقارير التغطية وحزم Offline
```

**لا تفترض أن OCR أو ASR يعرف الحرف المفرد جيدًا.** كثير من الحروف القصيرة ينطق بصوت مماثل لغيرها أو يُفهم خطأ، وقد يختلف النص المستخرج من PDF عن ما هو مطبوع. اتبع قاعدة الرفض عند التضارب.

## 5. سكربتات المعالجة المتوفرة (اختيارية وغير مطلوبة لتشغيل PWA)

| السكربت | استخدامه |
|---|---|
| `scripts/transcribe-book.py` | تفريغ محلي مع أوقات الكلمات بواسطة faster-whisper؛ يعتمد على توفر نموذج Whisper محلي مسبقًا |
| `scripts/ocr-book.py` | OCR عربي Tesseract على PDF؛ يحتوي مسارات Tesseract محلية خاصة ببيئة التطوير ويجب مراجعتها على جهاز جديد |
| `scripts/align_book.py` | أدوات مواءمة النص والتوقيت ومطابقة المرشحين |
| `scripts/build-word-audio.py` | استخراج مقاطع من تسجيل الصفحة الأصلية وفق شروط تحفظية |
| `scripts/link-page-local-asr.py` | مطابقة كلمة مع ASR **في الصفحة نفسها** وتحفظ الأدلة |
| `scripts/reuse-exact-word-clips.py` | استعمال سابق لملف كلمة مطابقة في مواضع أخرى؛ يحتاج تدقيق تشكيلي |
| `scripts/reuse-exact-letter-clips.py` | إعادة استعمال حرف تعليمي مطابق في الحرف والحركة والهمزة |
| `scripts/refine-chart-cells.py`, `scripts/align_letter_charts.py` | ضبط جداول الحروف التعليمية والخلايا |
| `scripts/audio-match-qa.py`, `scripts/letter-reuse-qa.py` | فحص الاتساق والتوافق والمسارات |
| `scripts/audio-coverage.cjs` | تحديث تقرير التغطية الحالي |

بعض أدوات OCR/ASR لها مكتبات Python غير مضمنة في المستودع مثل PyMuPDF وfaster-whisper وimageio-ffmpeg وTesseract. استخدم بيئة افتراضية محلية، ولا ترفع النماذج الضخمة أو مفاتيح الحسابات إلى المستودع دون قرار مشروع. لا حاجة إلى جهاز التدريب أو مزود سحابي.

## 6. ترتيب التنفيذ عند اعتماد دفعة أصوات

```bash
# تأكد من حالة الفرع قبل أي مولد يغير JSON
git status --short
# عالج العينة التي تملك تسجيلًا أصليًا وتطابقًا واضحًا فقط
# اختبر العينات الجديدة وسلامة كل المقاطع
python scripts/audio-match-qa.py
python scripts/letter-reuse-qa.py
node scripts/qa.cjs
node scripts/audio-coverage.cjs
node scripts/build-offline-packs.cjs
git diff --check
git status --short
```

لا تشغّل جميع مولّدات الأصوات تلقائيًا بالتتابع على بيانات إنتاج دون مراجعة مدخلاتها: بعضها يحرر `data/audio-library.json` ويقص ملفات جديدة، ومن الضروري الحفاظ على نسخ Git قابلة للرجوع.

## 7. المراجعة الاستماعية المطلوبة

عند الاستماع للمقطع ينبغي مقارنة نص الصفحة الأصلي مع التسجيل الفعلي، والتحقق من بداية الكلمة ونهايتها، وعدم وجود جزء من كلمة مجاورة، والفتح/الكسر/الضم والتنوين والشدة والمد. راجع معنى المقطع التعليمي: الحرف المنفرد لا يُعامل باعتباره الجزء الأول من كلمة في الجملة. سجل هوية المراجع وتاريخ القرار ودليل المصدر ثم غيّر `reviewed` بعد مراجعة فعلية فقط.

### سجل مراجعة عملي

| page | zoneId | printed | expected spoken | file | pass/fail | reviewer/date |
|---|---|---|---|---|---|---|
| 13 | p13-w19 | تَ | تَ (حرف مشكّل مستقل) | `segments[p13-w19].clip` | غير مراجع | — |

الأمثلة ليست اعتمادًا استماعيًا. لا تنشر نسب نجاح تمثل المراجعة البشرية إذا لم تحصل مراجعة بشرية حقيقية.

## 8. الترجمة واللغات

الكتاب موجود بطبعات متعددة؛ احفظ معرّف اللغة والطبعة والمراجعة. قد تختلف الصفحات والأمثلة؛ خرائط `data/edition-maps/` ليست دليلًا على أن كل صوت عربي يصلح لكل صفحة مترجمة. لا تكرّر الصوت تلقائيًا لكل اللغات دون قواعد مواءمة موثقة.

## 9. أمان الأصوات والتعديلات

كل تغيّر صوتي يجب أن يضيف ملف الصوت أو يحافظ على مساره الأصلي، ويحدّث `audio-library.json` وتقارير التغطية، ويعيد بناء Manifest ويحفظ البصمات، ويمر باختبار `node scripts/qa.cjs`. لا تدمج دفعة صوت كبيرة مع تغييرات V3 الحركية في PR واحد؛ سهّل كشف التراجعات وعزل مصادر الأخطاء.
