معاينة V3: https://madani-mobile-reader-qtdpopqxv-ahusamshs-projects.vercel.app/vision/camera-v2.html?engine=v3

## 1. البيانات المحفوظة وما لم يكتمل

التحقق المحلي من `main` وقت التدقيق: **1597 ملفًا متتبعًا**، بينها **19 ملف PDF**، **90 تسجيل صفحة** في `library-audio/`، **750 ملفًا صوتيًا** في `library-clips/`، وصور **104 صفحات** مرجعية. فُحصت كل مراجع `data/offline-packs.json` الـ**1320** وكانت متتبعة ومتوفرة، وكل روابط `segments.clip` الـ**906** كانت متتبعة وملفاتها موجودة. لا توجد مراجع صورة أو تسجيل ناقصة حسب هذا الفحص.

أما المحتوى الصوتي فليس مكتمل الربط: **906 من 3025 موضعًا**، ويبقى **2119 موضعًا** دون تسجيل فردي معروف. العديد من الروابط أُنشئت آليًا وتحتاج مراجعة استماعية بشرية. ملفات البيئة المؤقتة مثل `__pycache__` ونتائج اختبارات متغيرة على الكمبيوتر ليست جزءًا من الأصول المطلوبة.

في فرع V3 توجد ملفات إضافية `vision/v3/`، أدوات مقارنة ونتائج مسجلة، وإصلاحات حزم Offline و`.gitattributes`. لا تتعامل مع وجود الملفات باعتباره إثباتًا لاكتمال التعرف الميداني أو مراجعة النطق.

## 2. خريطة النظام

| الجزء | الملفات المهمة |
|---|---|
| قارئ PDF والواجهة | `index.html`، `app.js`، `style.css` |
| واجهة الكاميرا | `vision/camera-v2.html`، `vision/camera-v2.mjs` |
| محرك V1 | `vision/engine/` |
| محرك V2 | `vision/v2/engine-v2.mjs` |
| محرك V3 | `vision/v3/engine-v3.mjs`، `ink-layout.mjs`، `target-v3.mjs`، `page-discriminate.mjs` |
| عزل المعالجة والصوت | `vision/v2/vision-worker.mjs`، `audio-controller.mjs`، `content-audio.mjs` |
| فهرس رؤية الصفحات | `vision/data/ref-index.bin` |
| ربط الحرف/الكلمة بالتسجيل | `data/audio-library.json`، `data/audio-coverage.json`، `data/edition-maps/` |
| العمل دون إنترنت | `sw.js`، `vision/v2/offline-packs.mjs`، `data/offline-packs.json` |
| الاختبارات | `vision/bench/`، وملفات `*.test.mjs` |

خط التشغيل: كاميرا الهاتف → سمات الصفحة والجزء المرئي → تقدير طرف الإصبع/القلم → التحقق من الحبر/موضع النص → اختيار الموضع مع رفض اللبس → تشغيل التسجيل الأصلي الصحيح. أي حرف داخل كلمة ينبغي أن ينطق **الكلمة كاملة**، بينما الحرف التعليمي المنفرد ينطق حسب درس الكتاب. **لا تنطق** إذا لم توجد إشارة موثوقة أو لم يوجد التسجيل الصحيح.

V3 يحسن تحديد موضع **الحبر الفعلي** والتمييز بين الصفحات المتشابهة؛ **لم يُضف OCR عربيًا عامًا مستقلًا**.

## 3. استنساخ المشروع وتشغيله محليًا

الخطوات: ثبّت Git وNode.js حديثًا (اختبارات Claude استخدمت Node 22)، واستنسخ فرع V3. لتجارب Chrome الآلية ثبّت `playwright-core` ومتصفح Chrome. لا تحتاج Playwright عند استخدام التطبيق على الهاتف. اعمل في فرع منفصل، ولا تعدل `main` لتجربة الرؤية.

```powershell
git clone https://github.com/ahusamsh/madani-mobile-app.git
cd madani-mobile-app
git switch feature/vision-v3-accuracy
git status -sb
npm install --no-save --no-package-lock playwright-core@1.56.1
node scripts/serve.cjs
```

ثم افتح `http://localhost:8765/vision/camera-v2.html?engine=v3`، وقارنه بــ`http://localhost:8765/vision/camera-v2.html?engine=v2`. تشغيل التطبيق على الهاتف يحتاج HTTPS لاستعمال الكاميرا (أو localhost للتطوير).

**نقطة Windows مهمة:** بصمات الحزم حساسة لبايتات CRLF/LF. ملف `.gitattributes` في فرع V3 يفرض LF على ملفات JSON وملفات تراخيص PDF.js؛ إذا فشل فحص SHA-256، راجع `git ls-files --eol` واستخدم نسخة مستنسخة نظيفة. لا تُحدّث البصمات لمجرد إخفاء مشكلة تحويل الأسطر.

## 4. إعادة تشغيل الاختبارات

ابدأ باختبارات الوحدات والربط ثم اختبر الحزم والمحاكاة. الاختبارات المسجلة **65/65 ناجحة** على نسخة نظيفة من V3 بعد إصلاح Windows؛ ليست هذه نسبة دقة على الهاتف.

```powershell
node --test vision/recognition-core.test.mjs vision/engine/units.test.mjs vision/engine/engine.test.mjs vision/v3/v3.test.mjs vision/v2/v2.test.mjs vision/v2/full-book.test.mjs
node scripts/qa.cjs
node scripts/audio-coverage.cjs
node vision/bench/run-compare.cjs --pages=13,17,21,25,28,47 --zones=2 --engines=v2,v3 --source=pdf
node vision/bench/run-v2.cjs --engine=v3
node vision/bench/run-v2.cjs --engine=v2
```

التقارير المحفوظة: `vision/bench/results-v2-vs-v3.json`، `vision/bench/results-v3-offline.json`، `vision/bench/pdf-truth.json`. على **130 حالة محاكاة**: V2 صحيح 88، وV3 صحيح 103؛ لم يسجل التقرير اختيار كلمة خاطئة في تلك العينة، لكن V3 رفض حالتين كان V2 يتعرف عليهما. الصفحة 13 ومشكلة `p13-w19` اختُبر إصلاحهما آليًا. **لا يوجد اختبار ميداني كافٍ بكاميرا هاتف حقيقي**.

اختبار الموبايل المطلوب: إضاءة جيدة وضعيفة، قلم وإصبع، صفحات 13 و17 و21 و25 و28 و47 و60 و80 و100، صفحة جزئية، كلمات متجاورة، انعدام الإشارة، وبقاء المؤشر ثم انتقاله؛ سجّل درجة صحة الصفحة والكلمة والجار وزمن بدء الصوت. اختبر أيضًا التنزيل ثم فصل الإنترنت وإعادة فتح التطبيق.

## 5. تحديث الصور/الصوت/الفهارس

1. افحص كل رابط `image` و`clip` بعد إضافة أو تعديل أي صفحة/تسجيل، ولا تربط كلمة بصوت حرف غير مناسب.
2. إذا تغيرت صور الصفحة أو سمات المطابقة، أعد بناء `vision/data/ref-index.bin` في Chrome.
3. **بعد أي تغيير في ملفات الحزم** أعد بناء `data/offline-packs.json` حتى تتطابق بصمات SHA-256.
4. اختبر وحدة Offline والجودة، وحدّث نسخة Service Worker عند الحاجة. اختبر أن تحديث الحزمة لا يحذف الأصوات المطلوبة.

```powershell
# فقط عند تغيير الصور/السمات:
node vision/bench/build-index.cjs
# بعد تغيير بيانات تدخل في الحزم:
node scripts/build-offline-packs.cjs
node --test vision/v3/v3.test.mjs
node scripts/qa.cjs
```

## 6. حفظ العمل والنشر والتراجع

1. ارفع كل تعديل ناجح على فرع V3 واحتفظ بنتائج الاختبار وتاريخه في GitHub.
2. استخدم [PR #7](https://github.com/ahusamsh/madani-mobile-app/pull/7) للمراجعة، ولا تدمجه إذا بقي تراجع في التعرف أو لم يتوفر اختبار هاتف كافٍ.
3. اعرض V3 من معاينة مستقلة، ولا تغيّر رابط الإنتاج أو المحرك الافتراضي دون اجتياز معايير الجودة.
4. بعد قبول النتائج يمكن دمج الفرع في `main` ثم فحص GitHub Pages والوكيل Vercel (الرابط الخارجي بلا اسم درب باث)، وملفات الفهرس والصوت وSW والحزم.
5. أبقِ `?engine=v2` كمسار رجوع، مع `vision/camera-trial.html` للمقارنة. في حال فشل الإصدار الجديد أعد V2 كافتراضي وراجع التغيير، ولا تفترض أن المعاينة التجريبية تتزامن تلقائيًا مع Git.
6. لا تنشر ملفات بيانات اعتماد أو مفاتيح أو ملفات Cache مؤقتة، ولا تستخدم جهاز التدريب لهذه المهمة.

## 7. القيود الحالية التي يجب أن يعرفها أي مطور

- لم تُقَس دقة V3 على هاتف حقيقي بمجموعة بيانات كافية.
- تبقت حالتا رفض عند دوران الإصبع بالصفحتين 25 و28، وكذلك ضعف في إشارة قلم قصير من اليمين.
- الصفحات 60 و80 و100 تحتاج تصحيحًا لمخرجات نص/مواضع غير سليمة.
- بقي **2119 موضعًا** بلا ملف صوت منفصل، والروابط الآلية بحاجة مراجعة استماعية.
- أدوات التطوير الخارجية (Playwright، Chrome، Python وحزمها) ليست بالضرورة موجودة في المستودع؛ تثبَّت عند الحاجة، ولا يلزم وجودها عند تشغيل PWA على الهاتف.

**تسليم المطور:** استنساخ `main` وV3، قراءة هذا الدليل وREADME وPR #7، فحص البيانات والفهارس، إعادة تشغيل الاختبارات، تجربة الهاتف وتوثيق النتائج، ثم اتخاذ قرار الدمج أو إبقاء V3 في المعاينة.

هذا توثيق لإعادة إنتاج الحالة القابلة للتحقق، **وليس** نسخة حرفية من كل خطوات جلسة Claude Cloud أو تأكيدًا بأن كل تجربة ميدانية اكتملت.
